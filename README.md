# AlertasZaror1.0

Aplicación Android para la Junta de Vecinos Población Zaror, Cerrillos.

## Objetivo

Permitir que los vecinos registren alertas comunitarias con tipo de incidente, descripción, ubicación aproximada y evidencia opcional.

## Tecnologías

- Kotlin
- Jetpack Compose
- Arquitectura MVVM
- Persistencia local con Room
- Cámara y ubicación del dispositivo

## Alcance académico

Los datos utilizados son ficticios y sirven para demostrar el funcionamiento del MVP solicitado en la evaluación.
